# Royal Egypt Group Website

A free, static, multilingual (Arabic, English, Russian) website for Royal Egypt Group.

## Deploy with Cloudflare Pages

- Framework preset: None
- Production branch: `main`
- Build command: leave empty
- Build output directory: `/` (repository root)
- No build step or paid service is required.

The site entry point is `index.html`. Connect this GitHub repository to Cloudflare Pages and deploy.
